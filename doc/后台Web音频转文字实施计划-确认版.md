# 后台 Web 音频转文字实施计划（确认版）

> 状态：已实施并完成本地质检，待 Ubuntu 离线部署验收
>
> 日期：2026-08-30

## 1. 已确认需求

1. 功能是“音频转文字”，不增加跨语言文本翻译模型。
2. Web 直接利用项目现有 8885 平台 API：`POST /v1/audiototext`。
3. 不要求处理期间持续出现文字；上传时显示真实上传百分比，模型推理时显示不定进度和处理状态，完成后一次性展示结果。
4. 仅供内网访问，不建设账号、登录和多用户权限系统。
5. 页面不保存音频，前端不使用 IndexedDB/localStorage 缓存文件；用户已明确授权 8885 在请求结束后清理该请求目录中的上传文件及转换文件，不长期保留音频。
6. 保持现有 6006 通用 API、8885 平台 API、油猴脚本和模型服务合同不变。

## 2. 实现边界

本次只建设一个轻量内网单页 Web，不新增后台任务系统、SSE、WebSocket、数据库或翻译引擎。

```text
内网浏览器
  -> 8885 /                 Nginx 提供前端静态文件
  -> 8885 /v1/audiototext  Nginx 转发现有 FastAPI :6006
  -> 现有 Tailect_V4.1 模型返回转写结果
```

由于 `/v1/audiototext` 是同步接口，进度分为两个阶段：

- 上传中：通过浏览器上传事件显示 0%～100% 的真实上传进度。
- 处理中：上传完成后显示动态进度条和“模型正在处理”，不伪造模型内部百分比。

## 3. 页面功能

### 3.1 服务状态

- 请求同源 `/health`。
- 显示服务在线状态、模型名和模型是否就绪。
- 服务不可用时禁用提交按钮并显示错误。

### 3.2 音频选择

- 使用 Ant Design `Upload.Dragger`，每次只处理一个文件。
- 支持拖拽和点击选择。
- 在浏览器端校验文件大小和允许的音频扩展名；后端仍执行最终安全校验。
- 显示文件名、大小和移除操作。
- 不自动上传，用户点击“开始转写”后才提交。

### 3.3 转写选项

- 模型固定为 `Tailect_V4.1`。
- 识别语言由新模型自动检测，页面不提供语言输入。
- 提供“区分说话人”开关，对应 `diarize=0|1`。

### 3.4 状态与结果

- 状态：等待文件、上传中、模型处理中、完成、失败。
- 上传中显示真实百分比、已上传大小和总大小。
- 模型处理中显示不定进度，不伪造完成比例。
- 完成后展示接口返回的 `language`、`file_name`、`uuid` 和分段数量。
- 使用表格展示 `lid`、`begin`、`end`、`text`。
- 提供“复制全文”和“清空结果”；清空只清除浏览器内存状态，不调用删除接口。
- 处理失败显示 body 中的业务错误码和 `message`，并兼容 HTTP 网络错误。

## 4. 前端技术方案

新增 `tailect/web/`：

- React + TypeScript。
- Vite。
- Ant Design v6 与 `@ant-design/icons`。
- 使用 `XMLHttpRequest` 提交 `multipart/form-data`，以便获得真实上传进度。
- 不增加大型状态管理库；使用 React state/reducer 管理单任务状态。
- 开发环境代理 `/health` 和 `/v1` 到可配置的后端地址。
- 生产使用相对路径访问 8885，同源部署，不依赖宽泛 CORS。
- 固定依赖版本并提交 `pnpm-lock.yaml`。

实施前后遵循 Ant Design CLI 流程：查询组件 API和示例，完成后执行 `antd lint`。

## 5. 8885 部署方案

修改 `wxz/deploy/nginx_platform_8885.conf`：

- `/` 提供前端构建产物。
- 保留 `/health`、`/v1/audiototext`、`/translator/*` 的现有反向代理。
- 当前单页没有浏览器子路由，仅 `/` 和 `/index.html` 提供页面；其它未知路径继续返回平台 JSON 404，避免改变既有 8885 合同。
- 前端静态资源使用缓存，`index.html` 不长期缓存。
- 不更改 6006 FastAPI 监听方式，不新增模型进程。

构建产物采用明确的离线部署目录；具体现场路径保留为配置变量，不写死本机或生产 IP。
