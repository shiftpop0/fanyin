## 7. 维护规则

1. 新增项目级说明和计划时放入 `doc/`，并更新本索引。
2. `wxz/docs/` 只作为历史来源保留，不再新增或同步修改。
3. 专项测试数据、日志、迁移包和临时研究材料仍可留在 `wxz/` 对应分类目录；如需
   进入长期维护，应在本索引添加链接或迁入 `doc/`。
4. 不删除历史文档；需要废止时，标注状态或按项目规则移动到 `del/`。
