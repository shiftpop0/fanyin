# Tailect V4.1 独立油猴脚本

`spyware-translator-v4.1/` 是当前项目的 V4.1 专用客户端，不依赖旧项目目录。

当前脚本版本：`0.5.3`。

## 默认连接

- 平台 API：`http://127.0.0.1:8885`
- 模型：`Tailect_V4.1`（唯一选项）
- 本机 CSV 助手：`http://127.0.0.1:18885`
- 浏览器端识别并发：1；服务端也使用单进程 FIFO 队列。
- 请求只发送模型别名和 `diarize`；识别语言由新模型自动检测，不发送 `language` 或每行字符数参数。

模型部署在另一台内网电脑时，只需在脚本设置中把“服务地址”改成
`http://<模型电脑IP>:8885`。如果服务端设置了 `TAILECT_API_KEY`，在同一设置页填写 API Key。

## 安装

1. 将 `spyware-translator-v4.1.user.js` 导入 Tampermonkey。
2. 如需自动保存本机 CSV，双击 `local_helper/启动本机CSV助手.bat` 并保持窗口运行。
3. 打开目标业务页面，在悬浮面板中点击“检测模型服务”。检测不仅要求 `/health` 正常，还会核对服务模型必须为 `Tailect_V4.1`。

脚本在 Windows 浏览器中拼接 WAV。输入为双声道或多声道 PCM WAV 时，会先在本机将所有声道相加并进行峰值保护，生成单声道 WAV；展开按钮中的播放器和上传 `/v1/audiototext` 的分片都使用这份相同的单声道音频。`0.5.3` 会按 PCM 的声道数和位深重算采样帧宽，兼容业务 WAV 将双声道 `blockAlign` 错写成 `2` 的情况，同时继续拒绝不完整的 PCM 采样帧。随后脚本通过 `/translator/csv` 在模型电脑上保存一份 CSV。所有运行均可在离线内网完成。

## 检查

静态检查：

```powershell
node .\spyware-translator-v4.1\tests\userscript_static_test.mjs
node .\spyware-translator-v4.1\tests\userscript_audio_downmix_test.mjs
```

服务上线后，使用项目测试音频做真实合同探测：

```powershell
node .\spyware-translator-v4.1\tests\tailect_v41_probe.mjs http://127.0.0.1:8885 Tailect_V4.1 C:\path\to\sample.wav
```

若启用了 API Key，先设置同名环境变量 `TAILECT_API_KEY`；探测脚本会自动发送 `X-API-Key`。
