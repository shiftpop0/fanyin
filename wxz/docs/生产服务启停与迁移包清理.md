# Tailect V4.1 生产服务启停与迁移包清理

生产 release 固定为：

```text
/home/gezhi/fanyin/releases/new4.1-20260829
```

## 1. 启动

```bash
cd /home/gezhi/fanyin/releases/new4.1-20260829
bash wxz/deploy/run_v4_1_single_4090.sh start
```

脚本会依次等待并检查 `6006`、说话人分离、ForcedAligner 和 `8885`。成功时最后显示：

```text
Ready: generic API http://127.0.0.1:6006; platform API http://127.0.0.1:8885
```

## 2. 关闭

```bash
cd /home/gezhi/fanyin/releases/new4.1-20260829
bash wxz/deploy/run_v4_1_single_4090.sh stop
```

`stop` 只停止 `tailect-v41-platform` 和 `tailect-v41-model`，不删除容器、日志、模型或输出。

## 3. 重启

```bash
cd /home/gezhi/fanyin/releases/new4.1-20260829
bash wxz/deploy/run_v4_1_single_4090.sh stop
bash wxz/deploy/run_v4_1_single_4090.sh start
```

## 4. 状态与健康检查

```bash
cd /home/gezhi/fanyin/releases/new4.1-20260829
bash wxz/deploy/run_v4_1_single_4090.sh status
```

单独检查：

```bash
curl -fsS http://127.0.0.1:6006/health
echo
curl -fsS http://127.0.0.1:8885/health
echo
```

核心就绪字段应为：

```json
{
  "service_ready": true,
  "diarization_ready": true,
  "diarization_error": "",
  "forced_aligner_ready": true
}
```

当前独立标点模型目录为空，因此 `punctuation_ready=false` 不阻止服务启动，也不阻止油猴调用平台转写。

## 6. r6 及更早迁移包清理

r6 及以前的迁移压缩包和解压目录不参与当前容器运行；当前代码已经复制到 release，并应用了 r7 修复。清理前先执行只读核对：

```bash
docker inspect tailect-v41-model \
  --format '{{range .Mounts}}{{println .Source "->" .Destination}}{{end}}'

readlink -f /home/gezhi/fanyin/releases/new4.1-20260829/tailect/model
```

预期模型容器挂载来源是：

```text
/home/gezhi/fanyin/releases/new4.1-20260829/tailect -> /workspace
/home/gezhi/fanyin/tailect/model -> /workspace/model
```

确认没有挂载任何 `fanyin-new4.1-incremental-...-r1` 至 `r6` 目录后，将旧迁移包移动到保留目录：

```bash
cleanup_root="/home/gezhi/fanyin/del/migration_packages_before_r7_$(date '+%Y%m%d_%H%M%S')"
mkdir -p "$cleanup_root"

for item in \
  /home/gezhi/fanyin/fanyin-new4.1-incremental-20260829-r{1..6} \
  /home/gezhi/fanyin/fanyin-new4.1-incremental-20260829-r{1..6}.tar.gz
do
  [[ -e "$item" ]] || continue
  mv -- "$item" "$cleanup_root/"
done

printf '旧迁移包已移动到：%s\n' "$cleanup_root"
```

先保留该目录，完成真实双说话人验收并稳定运行一段时间后，再由管理员根据备份策略处理。

以下对象不能作为“r6 旧包”清理：

- `/home/gezhi/fanyin/releases/new4.1-20260829`：当前运行 release；
- `/home/gezhi/fanyin/tailect`：包含当前 release 正在复用的 `model/`，也是旧容器回退基础；
- `/home/gezhi/fanyin/tailect/model`：当前全部模型；
- `tailect-asr-qwen3-asr-full-diar-offline.tar`：离线镜像恢复介质；若没有另一份可靠备份应继续保留；
- r7 压缩包和解压目录：至少保留到验收完成；
- `releases/new4.1-20260829/wxz/hotfix_backups/`：r7 更新前文件备份；
- `tailect-v41-model`、`tailect-v41-platform`、`asr_instance_6006` 容器及现有 Docker 镜像。
