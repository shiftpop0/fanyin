# 语音网页翻译脚本开发指南

## 0. 项目目标

目标：开发一个油猴 JS 脚本，在目标网页中获取语音音频并接入本地模型翻译，按句展示译文。开发以鲁棒性优先。

约束：
- 临时文件/临时脚本统一放在 `./spyware-translator/temp`。
- 允许写带删除逻辑的代码，但任何实际删除操作（删除文件/执行删除命令）都必须先征得你同意。

## 1. `prompt材料` 使用约定

1. `prompt材料/VX界面`：后续拓展功能使用，当前阶段不纳入主流程。
2. `prompt材料/功能界面截图.png` + `prompt材料/功能界面部分代码.txt`：用于复现目标网站核心区域。
- 当前要求：只复现未打码核心部分。
- 复现原则：核心 DOM 结构以提供代码为准，只做必要修复（坏标签、乱码、缺失样式）。
3. `prompt材料/bian.wav`：测试音频样本。
4. `prompt材料/音频报文txt`：播放音频接口样本（响应 `audio/x-wav`），用于设计抓流策略。
5. `prompt材料/spyware-dataquery.user.js`：油猴脚本参考（`@match`、`@grant`、`@run-at` 等）。

## 2. 总体路线

1. 阶段 1：复现原环境。
2. 阶段 2：在原环境注入 JS 测试。
3. 阶段 3：提取为独立油猴脚本并测试。
4. 阶段 4：拓展其他类似功能。
